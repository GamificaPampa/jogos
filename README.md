# Jogos dos professores

Galeria dos jogos que os professores criam com a IA e publicam pelo [Publicador](https://gamificapampa.github.io/publicador/). Endereço: [gamificapampa.github.io/jogos](https://gamificapampa.github.io/jogos/)

Cada jogo fica numa pasta com o `index.html` e o `jogo.json` (nome do jogo, escola e data). Os dados de quem publicou ficam no repositório privado `jogos-registro`, nunca aqui.

O workflow [pages.yml](.github/workflows/pages.yml) monta o `jogos.json` a partir das pastas e publica tudo no GitHub Pages a cada push. Para remover um jogo, apague a pasta dele.
